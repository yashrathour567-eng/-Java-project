# Cura — Online Health Consultation Platform

A polished, pure-Java desktop prototype for patients, healthcare professionals, and administrators. The interface is built with Java Swing and uses only the JDK; no external libraries or network connection are required.
## Run

Install a JDK (Java 14 or newer), open a terminal in this folder, then run:

```text
javac HealthConsult.java
java HealthConsult
```

## Explore

Use the role selector at the top right to switch between Patient, Healthcare professional, and Admin workspaces. Each role has its own dashboard and navigation. Patient appointment booking, user creation, profile editing, health record entry, provider availability, and system settings include interactive forms and confirmations. Sample records and appointments are included to make the screens feel alive on first launch.

This is a front-end prototype: information is held in memory and resets when the app closes. It is not connected to a medical record system and should not be used to provide real medical care.
